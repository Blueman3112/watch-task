# Watch-Task 项目全界面功能白皮书

本文档系统性地梳理了本项目（智能手表螺旋任务管理 App）的所有核心交互界面及其功能。本应用严格遵循 Wear OS 原生极简设计理念，以全屏沉浸和手势交互为核心，抛弃了传统的“多重嵌套列表”。

---

## 1. 核心主视界：雷达螺旋线 (Main Spiral Screen)

这是应用的心脏与灵魂，也是应用启动后展示的第一且唯一的常态化全景界面。

*   **视觉隐喻**：深空黑底色搭配幽绿色轨道线，所有未完成的任务像星体一样沿着黄金螺旋轨道向屏幕中心点（处理区）排队逼近。
*   **基础交互**：
    *   **滚动浏览**：深度适配手表的“物理表冠（Rotary Crown）”和屏幕垂直滑动。用户转动表冠，整个任务序列会沿着轨道顺滑地进退，且离中心越近的任务尺寸会非线性放大。
    *   **单点穿透**：点击最中心的任务节点，或者点击轨道后方的任意一个小节点，均可直接穿透进入该任务的**「任务详情页」**。
*   **红圈戒严状态 (System Lockdown)**：
    *   这是本系统最独特的设计。当排在最中心处理位的任务优先级为 `EMERGENCY`（紧急）时，全系统进入锁死状态。
    *   **视觉表现**：屏幕边缘亮起高压迫感的红色脉冲光晕，上方悬浮黑色粗体 **"LOCKED"**。
    *   **操作拦截**：在此状态下，表冠滚动失效、长按新建失效，强制逼迫用户点击眼前的红色任务去处理。

## 2. 新建入口：极简添加页 (Add Task Screen)

当系统**未被锁定**时，在主界面中心区域**长按**，即可唤起本页面。

*   **设计理念**：针对 1.4 英寸屏幕特化的全屏流式滚动页面 (`ScalingLazyColumn`)，剔除了一切多余的中文字符和分割线。
*   **核心构成**：
    *   **外部接入快捷区 (Demo 高光区)**：位于页面最顶部，提供两个高质感的按钮——绿色的【微信导入】和蓝色的【日历同步】。这是专为录屏演示设计的 Mock 接口，点击后页面瞬间关闭，强行插队一条突发任务回主界面。
    *   **手动表单区**：采用大字号无边框输入框，用户可配置标题、描述、日期、时间。
    *   **优先级选择盘**：采用四个纯色原点（红、黄、绿、灰）代替文字选择器，直觉化选定紧急程度。
    *   **极简操作底栏**：废弃了“保存/取消”文字，采用纯灰色的 **✖️ (取消)** 与墨绿色的 **✔️ (保存)** 纯图标按钮。

## 3. 信息出口：任务详情页 (Task Detail Screen)

在主界面点击任何一个球体节点后进入的阅读与决策视窗。

*   **设计理念**：强调信息的主次分级，使用胶囊标签替代长文本，让阅读焦点集中在任务名称上。
*   **核心构成**：
    *   **溯源与状态标签**：顶栏采用高度可视化的彩色胶囊。例如如果任务来自微信，顶部会有一个半透明微信绿色的 **"微信导入"** 标签紧贴着优先级时间标签，身世一目了然。
    *   **滚动文字区**：用于展示由于标题过长无法在主屏显示的详细备注。
    *   **极简决策底栏**：底层分布着至多三个原生交互图标：
        *   **✖️ (关闭)**：什么也不做，退回主螺旋。
        *   **⬆️ (置顶)**：如果任务在后排，点击后可直接将其提拔到螺旋最前方（中心位置）。
        *   **✔️ (完成)**：这是消灭任务的唯一途径。点击后任务数据被销毁，退回主界面，若是因此消灭了紧急任务，系统红圈警报会随之解除。

## 4. 特殊交互层：置顶预览模式 (Top Mode Overlay)

这是一个叠加在主界面之上的临时态 UI，主要用于对后排任务进行“越级提拔”。

*   **触发方式**：在主界面中，对轨道中后排的任意一个较小节点执行**长按**操作。
*   **视觉表现**：
    *   除了被选中的节点会放大并亮起外，其余所有节点都会大幅度变暗并透明化（场效应衰减）。
    *   屏幕正中心出现一个高亮的同心圆靶心，并显示纯白色的 **"TOP"** 字样。
    *   屏幕最下方的边缘弧线上，会用环形文字打印出当前选中任务的名称，方便用户确认。
*   **交互闭环**：此时用户如果点击中心的 "TOP" 靶心，被选中的任务就会像被黑洞吸入一样瞬间飞跃至排队序列的第一名；如果不点中心而点击其他空白处，则取消该预览模式。
