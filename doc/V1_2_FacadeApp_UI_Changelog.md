# V1.2 版本更新日志：门面伴侣应用构建与雷达视觉调优

本次更新重点补全了智能手机端的缺失生态，利用“门面模式（Facade）”打造了美观且高效的手机端任务控制中心，同时对 Wear OS 端的极限 UI 表现进行了像素级的视觉重构与自适应修复。

## 手机端 (Mobile / Facade App) 核心特性
1. **控制中心 UI 重构 (Jetpack Compose)**
   - 彻底废弃了仅用于申请权限的临时界面，重写了一套完全贴合手表暗黑科技风格的“Watch-Task 控制中心”。
   - 包含自定义的输入表单、直观的四个颜色优先级选项卡卡片，以及整合的 Android 原生日期/时间选择滚轮。
2. **底层日历劫持写入 (Calendar Write)**
   - 在 `AndroidManifest` 中增加了 `WRITE_CALENDAR` 权限。
   - 实现了对系统日历的透明写入：用户选择“紧急”后，App 自动在底层拼接 `!紧急` 魔法标签并插入 `CalendarContract`，优雅地实现了对原生业务逻辑的复用。
3. **全自动穿透同步 (Auto-Push Sync)**
   - 解决了手表容量满载后无法点击同步的“死锁”痛点。
   - 改造了 `WearSyncService` 监听器，手机端在点击保存后会立刻向后台派发 `ACTION_FORCE_SYNC` 广播。
   - 实现“手机建任务 -> 瞬间强制触发生态穿透 -> 手表雷达立刻响应变红”的丝滑互联体验。

## 手表端 (Wear OS) 视觉与适配调优
1. **时间胶囊动态自适应排版 (Dynamic Text Measuring)**
   - 修复了真机环境下顶部时间胶囊文本拥挤重叠的严重 Bug。
   - 弃用死板的固定弧度，改用底层 `Paint.measureText()` 实时测算文本像素长度。
   - 实现了三个状态胶囊基于中心轴的动态膨胀与自适应避让，绝对确保 12度 的完美等距缝隙。
2. **锁死动效好莱坞化 (LOCKED Visual Polish)**
   - 废除了粗糙直白的 "LOCKED" 悬浮文字。
   - 引入 Jetpack Compose 的 `Brush.radialGradient` (径向渐变) 技术，在表盘 85% ~ 100% 的极窄边缘区域，绘制了一圈由外向内消散的血红色光晕。
   - 配合心跳呼吸动效 (`pulseScale`)，大幅提升了应用遭遇极度紧急任务时的视觉压迫感与高级质感。
3. **安全边距重置**
   - 抬高了详情页任务标题的 `Spacer` 防撞隔离带，杜绝了多行标题溢出至顶部胶囊区域的排版事故。
