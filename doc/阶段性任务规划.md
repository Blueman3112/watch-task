## 阶段2：双色状态系统（绿/红）

### 目标
用绿色（正常）和红色（警戒）两种主色调贯穿整个界面，替代当前的单色 teal 方案。

### 具体内容

**2.1 颜色映射规则**

| 状态 | 颜色 | 适用条件 |
|------|------|---------|
| 正常（绿） | `#4CAF50` 系列 | 优先级为「待处理」「长远」的任务 |
| 警戒（红） | `#FF5252` 系列 | 优先级为「紧急」「重要」的任务 |

**2.2 改造范围**
- 螺旋节点颜色：根据任务优先级动态显示绿/红
- 螺旋引导线：保持低透明度中性色
- 中心核心球：根据当前最高优先级任务显示对应颜色
- 任务详情页：标题栏/标签颜色随优先级变化
- 呼吸动画：红色节点呼吸频率更快（已有基础），绿色节点呼吸平缓

**2.3 来源标识**
- 不同来源的任务在节点上加微妙的视觉区分（如：日历任务带小圆环、微信任务带小方块标记）

### 涉及文件
- `presentation/components/TaskComponents.kt` — 螺旋画布颜色逻辑重构
- `presentation/MainActivity.kt` — 通知条颜色适配

### 验收标准
- [ ] 紧急/重要任务节点显示红色系
- [ ] 待处理/长远任务节点显示绿色系
- [ ] 中心核心球颜色随最紧急任务联动
- [ ] 三种来源的任务有细微视觉区分
- [ ] 整体只保留绿/红两个主色调，界面更简洁

## 阶段3：螺旋有机生长算法（核心）

### 目标
实现"自然有机体生长"效果 —— 任务不断加入时螺旋体逐步长大，达阈值后停止运动。

### 具体内容

**3.1 生长算法核心逻辑**

```
当前任务数 N → 决定螺旋体的"生长阶段"
  N = 1~3   : 胚芽期，螺旋很小，节点紧凑
  N = 4~7   : 生长期，螺旋明显展开，节点逐渐散开
  N = 8~10  : 成熟期，螺旋接近最大，节奏放缓
  N = 11+   : 饱和期，停止生长动画，提示用户需要清理
```

**3.2 关键参数动态化**

| 参数 | 当前值（固定） | 改为动态 |
|------|--------------|---------|
| `spiralA`（起始半径） | 42f | 随 N 从 20f → 42f 增长 |
| `spiralB`（间距系数） | 14f | 随 N 从 8f → 14f 增长 |
| 节点大小 `baseSize` | 11f | 随 N 从 14f → 9f 缩小（越多越小） |
| 呼吸幅度 | 固定 | 饱和期：呼吸放缓直至停止 |

**3.3 生长动画**
- 每当新任务加入时，播放一次"伸展"动画（spiralA/spiralB 从旧值过渡到新值）
- 动画曲线采用 `EaseOutBack`，营造弹性生长感
- 任务被完成/移除时，播放"收缩"动画

**3.4 饱和提示**
- 任务数达到阈值（如11个）后：
  - 呼吸动画停止或极慢
  - 中心核心球脉冲加强（提示"需要处理"）
  - 可选：在边缘显示"任务饱和"提示文字

### 涉及文件
- `presentation/components/TaskComponents.kt` — `RadarSpiralScreen` 大幅重构

### 验收标准
- [ ] 1个任务时螺旋很小，12个任务时螺旋铺满屏幕
- [ ] 新增任务时有可见的"生长"过渡动画
- [ ] 完成任务时有"收缩"过渡动画
- [ ] 达到饱和时视觉上有明显提示
- [ ] 动画流畅无卡顿（需在真机测试）

## 阶段4：任务排队与节奏机制

### 目标
新任务进入螺旋体时有"排队入场"效果，不同来源的任务有不同的入场节奏。

### 具体内容

**4.1 排队入场动画**
- 新任务不再瞬间出现在螺旋上
- 改为：从屏幕外沿螺旋路径"滑入"到目标位置
- 多个任务同时加入时，按先后顺序逐个入场（间隔 300~500ms）

**4.2 节奏系统**

| 来源 | 入场节奏 | 视觉表现 |
|------|----------|---------|
| `CALENDAR` 日历 | 平稳、有规律 | 匀速滑入，无特效 |
| `MANUAL` 手动 | 中等节奏 | 常规滑入，轻微弹跳 |
| `WECHAT_IMPORT` 微信 | 突发、快速 | 快速弹入 + 闪烁强调效果 |

**4.3 Demo模拟**
- 在Demo模式下，启动后自动按预设节奏逐个添加任务：
  1. 先加载 4 个日历任务（均匀间隔 1s）
  2. 再加载 3 个手动任务（间隔 1.5s）
  3. 突然插入 2 个微信任务（间隔 0.3s，模拟突发）
  4. 继续加载剩余任务
- 这样可以在演示视频中完整展示排队和节奏效果

### 涉及文件
- `presentation/components/TaskComponents.kt` — 入场动画
- `presentation/TaskViewModel.kt` — 添加任务队列与定时调度逻辑

### 验收标准
- [ ] 新任务有沿螺旋路径滑入的入场动画
- [ ] 多任务排队时可见"一个接一个"的顺序效果
- [ ] 日历/手动/微信三种来源的入场节奏肉眼可辨区分
- [ ] Demo模式下可自动演示完整的排队+节奏流程

```
0s      启动 → 空白螺旋，中心呼吸等待

5~8s    手动任务逐个入场（绿色/红色，3个）
9~10s   微信任务突然弹入（红色，2个突发）

16s     达到饱和，螺旋停止生长
17s+    用户交互：旋转表冠浏览 / 点击查看详情 / 完成任务后螺旋收缩
```
